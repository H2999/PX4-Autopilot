# DM-FC01 自动翻正（实验功能）

分支 `codex/dshot-turtle-mode`，基于 `e8ea76e7a3`，保留该提交的BMI088主IMU配置。用户截图的电调为Bluejay0.21.0、48kHz。本功能默认关闭。上一版3.5秒脉冲固件已通过USB烧录并回读参数，用户随后报告倒扣场景可翻正；这属于用户现场反馈。正立扶正分支本机尚未执行烧录或实机验证；用户后续反馈小高度差难触发、持续时间过短，本轮据此降低入口并延长正立脉冲。

## 模式与配置

这是与Stabilized/Position并列的独立 **Turtle** 模式。固件通过AVAILABLE_MODES/CURRENT_MODE发布名称，参数元数据也包含选项；QGC实际界面仍待连接验证。

- `COM_FLTMODE1..6`的Turtle值为 **17**，沿用`RC_MAP_FLTMODE`模式通道。QGC未刷新选项时可重新获取本固件参数元数据，在参数页设置槽值17。
- 内部nav_state=7，自定义主模式=12，MAVLink custom_mode=786432；保留其他模式编号。此版本必须有有效RC，即使通过QGC选择模式也一样；无遥控器的上位机控制尚未加入。
- 倒扣拒绝普通解锁不妨碍选择Turtle：本模式在**上锁状态**独立输出，不需要先解锁。已解锁时拒绝进入；选中模式或方向恢复未完成时，拒绝所有来源的解锁，包括强制解锁。

| 参数 | 默认值 | 范围/含义 |
|---|---:|---|
| TRTL_EN | 0 | 完成拆桨核对后设1才启用 |
| TRTL_PWR | 0.6 | 0.05–0.8，恢复归一化油门上限，非实际推力百分比 |
| TRTL_RATE | 4 rad/s | 0.5–6 rad/s，软角速度目标；接近目标时减小油门 |
| TRTL_PULSE | 3.5 s | 0.1–6 s，倒扣单次推力脉冲上限 |
| TRTL_LPULSE | 5 s | 0.1–6 s，正立扶正单次推力脉冲上限 |
| TRTL_TOUT | 10 s | 2–20 s，总尝试时限，含停桨、换向、推力和落稳确认 |

倒扣单次脉冲默认3.5秒，正立单次脉冲默认5秒，各自最大6秒；总时限默认10秒，避免换向及落稳确认截断长脉冲。姿态/速率/失效/切出条件仍会提前停推；已有保存值需显式设置，刷写不会覆盖。

当前80%版本已通过限幅回归和构建；在旧约2.1843kg有罩模型中，输出封顶0.8后未能翻起，20秒超时。此前100%上限的翻正结果不能作为80%版本的通过证明。

当前Turtle输出有0.8硬限幅；旧配置即使保存为1.0，也最多按0.8输出。默认已改为0.6，正常飞行输出不受此限幅改动影响。固件默认值变更不会覆盖设备上已保存的TRTL_PWR；已有设备需显式设为0.6才使用60%设置。默认参数没有经过实机动力调校。角速度4rad/s约229°/s，独立硬截止仍为8rad/s。仿真所用功率、脉冲和时限不是实机推荐值。

## 正立倾斜扶正

同一个Turtle模式在地面静止入口分类：总倾角≥3°且<90°时，按转子位置选择物理低侧的一对电机，以保存的正常旋向（DShot20）产生向上推力；不发送临时反转21。到总倾角≤1°立即撤推，落稳且角速度<0.1rad/s连续2秒才完成。入口倾角不足3°不输出，需切出重进才重试。左右、前后及组合姿态均按重力投影决定，不按绝对yaw或固定电机编号。

启动门槛由30°降为3°时，停推也由15°降为1°，防止刚进入便被旧停推阈值截断。低于3°仍保留死区，避免近水平时按IMU噪声选边；IMU判断的是倾角，不直接测两侧离地高度。

正立分支保持同一方向策略，不在运动中来回换向；若翻到≥90°则终止，需落稳并切出重进。正立扶正角速度软目标限制为min(TRTL_RATE,1rad/s)，正立单次脉冲改为TRTL_LPULSE，默认5秒、最大6秒；倒扣仍用TRTL_PULSE默认3.5秒，总时限10秒不变，失效/切出等互锁不变。重试前须再次满足地面静止500ms，不会在悬空观察阶段加力。`turtle_status.levelling`标识所选正立分支，reason9表示不在当前恢复姿态范围。

这是一段受限地面扶正动作，不是悬停或地形规划。倾斜支撑面可能使机体在停推后再次倾斜；未落稳只能在总时限内重试，不能保证在任意坡面保持水平。按最新小倾角要求改为3°启动/1°停止，尚未完成实机调校。

本轮10°坡Gazebo已验证小倾角入口、低侧正常方向、第一段约4.99秒输出、总超时停推和切出约92ms停推，桨接地记录0。固定坡面最终仍10°，此结果不是扶平到1°的成功证明；新固件本机尚未烧录。

## 倒扣自动行为

1. 首次启用时先停桨300ms，向四个配置输出发送恢复保存方向的DShot20命令；至少10帧且至少100ms的本机序列完成后才给出解锁就绪。上电已选中Turtle不会自动开始，需要先切出再进入。
2. 进入前须上锁、低油门（归一化<-0.8）、roll/pitch/yaw摇杆居中（绝对值<0.15）、RC有效、安全开关允许输出、无急停/lockdown/termination/失效/校准。地面信息、加速度模长7–12.5m/s²、角速度<0.15rad/s连续满足500ms。静止FRD加速度Z正向且总倾角>100°才开始；不满足则本次不输出，需切出重试。
3. 按当前重力方向与实际转子几何选择较高侧的一对相邻电机。停桨300ms，发送相对反转DShot21至少10帧/100ms，50ms内缓升推力。油门随角速度接近TRTL_RATE而减小；软调节可在同一脉冲内恢复加力，8rad/s硬限则结束脉冲。脉冲到时也停止。
4. **首次总倾角≤60°先撤销推力**。若落稳后仍超过30°，后续尝试改为到30°撤推，优先完成翻正。停桨、恢复保存方向后无动力观察；运动中用估计器四元数，合格静止后用加速度重力方向核对并重新选对，推力期间不直接用加速度算倾角。
5. 再次脉冲必须重新满足地面静止500ms。达到≤30°后还须角速度<0.1rad/s、姿态保持在阈值内连续2秒，才锁定完成。落稳超过30°则在原总时限内继续；同轴落稳后无明显进展时，按当前姿态选择另一轴上更有利的一侧尝试。不会选择与当前翻正方向相反的备选；不使用固定ESC编号重试。
6. 撤推后的短暂失重只允许继续无动力观察，不允许在空中启动新脉冲；推力阶段的失重仍停止尝试。切出、RC/IMU失效、抬油门、动摇杆、急停、超时等也立即撤销推力并恢复方向。成功或终止后须切出再进入才会再次尝试；不会自动起飞。

按用户最新授权优先稳定翻正：首次60°给惯性机会，落稳失败后使用30°停止角，最终完成判据为≤30°且连续静止2秒。这个判据不代替正常解锁检查。

## 姿态、几何与方向

动态重力方向为`g_body=R(q)^T*[0,0,1]`（FRD→NED四元数）。静止合格时用`g_body=-acceleration/|acceleration|`核对。反推沿机体+Z，力矩约为`[sum(y),-sum(x),0]`，翻正方向为`[-g_y,g_x,0]`；比较点积选取相邻对。

绝对yaw单独变化不会改变机体哪一侧较高，因此不需要按机头朝北/朝南硬切电机编号。完全180°且四侧等高时无唯一方向，几何右侧用于打破数学对称，实际噪声也可能打破对称。IMU不能识别地面障碍、卡桨或反推效率。

- 仅支持`CA_AIRFRAME=0`、四个共面Quad-X转子（FRD每象限一个），读取`CA_ROTOR0..3_PX/PY/PZ`和真实输出功能映射。四个电机须全部在同一DShot输出实例上，无额外负载。实际位置/安装方向必须正确。
- 保持正常飞行已核对的Bluejay Normal/Reversed；`DSHOT_3D_ENABLE=0`、`CA_R_REV=0`。不为本模式启用3D，不发送保存命令12。已有CLI `dshot normal/reverse`使用7/8固定方向，不能代替本功能的20/21相对方向。
- 摇杆样本<500ms（RCUpdate不变时每300ms重发），同时独立检查原始RC接收<300ms及lost/failsafe；姿态/角速度/加速度<100ms且数值有效，Commander状态<750ms，地面检测<1500ms。
- 模式关闭普通飞行控制器，恢复逻辑独占输出；清理/拒绝电机测试和电调配置。TRTL_EN=1时缺失/过期300ms的恢复状态也禁止解锁。软件重启且ESC未断电时，首次启用仍先恢复保存方向。
- `ready_for_arming`只证明本机完成发送序列，**不证明真实ESC已执行或转向已测量确认**。如果中断后无法恢复，应断开动力电源，重新拆桨核对。

## 构建与Gazebo验证

控制器在`src/lib/turtle_recovery/TurtleControl.{hpp,cpp}`，纯状态机在`TurtleRecovery.hpp`。实机DShot与Gazebo共用传感器、RC/模式、姿态、几何、状态机和解锁就绪逻辑；Gazebo仅在最终ESC接口用有符号转速模拟20/21。

```bash
bash src/drivers/dshot/tests/check_turtle.sh
cmake --build build/px4_sitl_default --target px4 -j4
cmake --build build/damiao_dm-fc01_default -j4
python3 Tools/turtle_recovery/gazebo_recovery.py \
  --output /tmp/turtle-yaw180 --case yaw180 --yaw 180 --model guarded \
  --power .8 --pulse 1 --rate 3.5 --timeout 20
# 平地另加 --slope-roll 0；必须顺序运行，各用一个新的输出目录
python3 Tools/turtle_recovery/gazebo_recovery.py \
  --output /tmp/turtle-cancel --case cancel --fault cancel --power .15
```

本机依赖Gazebo Harmonic8.14.0（transport13/msgs10）、Python Gazebo绑定和pymavlink。运行器只访问隔离本机Gazebo/PX4及127.0.0.1模拟RC，写独立SITL参数，不发解锁。模型在EKF启动前倒扣落稳，启动后不施加外力/位姿干预。用户已确认有防护圈/罩且倒扣时桨不触地。默认`--model guarded`在原版X500上增加刚性方形上防护框：框条中心跨度0.72m（外沿0.77m）、管半径0.025m、框中心高于base 0.15m（顶面高于桨面约0.115m）、附加质量0.12kg、惯量diag(0.0104,0.0104,0.0208)kg·m²，总模型质量约2.1843kg。**这些尺寸/质量是仿真假设，未从实机测量**；不是实机保护罩的精确复现。原版base/转子质量、惯量、桨碰撞体、起落架和电机系数均保留，CA位置仍从SDF读取。

五个接触监测主题须全部被Gazebo发布；初始必须检测到防护框接地、无桨接地，整个恢复期间桨接地记录必须为零。Contact系统按物理步进记录非空接触消息。每个用例保存生成的模型SDF及校验值，可用`--model stock`保留无罩对照（新控制器仍按30°验收）。模型示意和完整假设见本轮`guard-model.png`及results.json。

验收独立读取Gazebo真实姿态/转子高度/四路输出，要求高侧选对、模式正确、最后≤30°且静止、停桨、reason=5及退出恢复就绪。故障用例要求反推期间切出/丢RC后500ms内停输出并恢复。真值不参与控制。仿真电机正反推力对称，真实普通桨反推效率、卡桨、ESC命令执行和实机接触几何仍须分别验证。

## 实机核对与状态

新增正立扶正分支尚未部署、板测或实飞；上一版已烧录且用户报告倒扣翻正成功。先备份参数、刷匹配DM-FC01固件并拆桨核对电机位置/正常方向/临时反向/退出恢复，再检查切出、急停、失联、恢复期间解锁拒绝；带桨地面验证由用户另行安排。

NSH使用`listener turtle_status`：state 0空闲、1停桨准备反转、2反转命令、3推力、4停桨准备恢复、5恢复命令、6无动力等待/确认、7等待切出。reason 0尝试中、1关闭、2输入失效、3几何无效、4旧版未倒扣（编号保留）、5落稳完成、6超时、7切出取消、8角速度高（结束当前脉冲，可在落稳后继续）、9不在恢复姿态范围。tilt为控制器当前使用的总倾角（弧度），power为当前归一化油门输出。
